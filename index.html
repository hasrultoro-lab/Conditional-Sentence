Type 1: Masih Mungkin

Real Possibility 🎯

Dipakai buat rencana atau hal yang peluang terjadinya besar di masa depan kalau syaratnya terpenuhi.

If + V1 (Present), S + will + V1
2

Type 2: Nggak Mungkin

Imaginary / Khayalan 🦄

Dipakai buat berandai-andai hal yang mustahil atau bertentangan dengan kenyataan sekarang.

If + V2 / were, S + would + V1
